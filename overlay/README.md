# JMBN Polaris Overlay
Windows x64 companion display for the JMBN Manifest System.

V1 is a transparent, always-on-top Polaris diagram shell. It is a separate companion window and does not interact with Star Citizen internals.

The GitHub workflow builds a self-contained single-file JMBNOverlay.exe. Live authenticated JMBN crew assignments will be wired in the next step without embedding privileged credentials.
