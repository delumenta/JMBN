# OnTheGo

OnTheGo is the public, no-login copy of the Japan travel app.

Open the site at:

`https://delumenta.github.io/onthego/`

The login, password-reset, and forgot-password pages are intentionally not included. Read-only itinerary pages can be opened publicly with a trip link such as `schedule.html?trip=1` when that trip is allowed for public reading in Supabase.
